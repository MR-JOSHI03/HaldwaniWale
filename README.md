# Clean Haldwani & friends

Everything is in this one folder. No build step.

Deploy on Vercel: import this folder at vercel.com/new -> Framework preset "Other",
no build command, output directory "./". Or run `vercel --prod` inside the folder.

Files:
- index.html                the page
- bg.jpg                    background photo
- logo-<handle>.png         profile pictures (6)
- preview-<handle>.jpg      profile screenshots shown when a card flips (5)
- post-clean-1.jpg / -2.jpg the two Clean Haldwani posts in the hero

To update a screenshot or DP, replace the file with the same name and redeploy.
